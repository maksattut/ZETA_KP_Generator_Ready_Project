ZETA — ГЕНЕРАТОР КОММЕРЧЕСКИХ ПРЕДЛОЖЕНИЙ

Готовый веб-сервис для торгового представителя Нурмухамеда Нурсултана.

ВОЗМОЖНОСТИ:
- добавление неограниченного количества позиций;
- количество, единицы измерения и цена;
- автоматический расчет суммы каждой позиции;
- автоматический расчет общей суммы;
- сумма прописью;
- номер и дата коммерческого предложения;
- клиент / компания;
- дополнительное примечание;
- сохранение черновика в браузере;
- живой предпросмотр;
- профессиональный PDF формата A4;
- адаптация под телефон и компьютер.

ПУБЛИКАЦИЯ НА GITHUB PAGES:
1. Создайте репозиторий.
2. Загрузите все файлы из архива.
3. Settings → Pages.
4. Branch: main, папка: /root.
5. Save.

ВАЖНО:
PDF-генерация использует jsPDF и AutoTable через CDN. При первом использовании
сайту необходимо интернет-соединение для загрузки библиотек.

ФАЙЛЫ:
index.html — интерфейс
style.css — дизайн
script.js — логика и PDF
README.txt — инструкция
